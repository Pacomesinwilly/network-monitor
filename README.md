# 🔍 Network Monitor

Outil Python de surveillance réseau local — scan automatique des IPs, ping, et logs horodatés.

## Fonctionnalités
- Scan des IPs 192.168.1.1 → 192.168.1.20
- Détection des hôtes actifs/inactifs
- Log automatique dans `log.txt` avec timestamp
- Rapport terminal propre

## Utilisation

```bash
python network_monitor.py
```

## Technologies
- Python 3
- subprocess, datetime, platform
